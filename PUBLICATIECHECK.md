# Publicatiechecklist voor Canvas

Deze repository is **opnieuw en afzonderlijk aangemaakt**, zodat oudere interne commits uit de ontwikkelrepository niet worden meegepubliceerd.

- [x] Aparte repository met nieuwe geschiedenis
- [x] Geen vertrouwelijke opdrachtgeverdocumenten
- [x] Geen echte backlogexport of privéprojectlinks
- [x] Geen inloggegevens, tokens of persoonsgegevens van derden
- [x] Alleen fictieve demo-invoer en testdata
- [x] Duidelijke uitleg van Copilot-agent versus reproduceerbaar voorbeeldscript
- [ ] Laat Projectteam 721 de inhoud bekijken vóór openbaarmaking
- [ ] Controleer eventuele toe te voegen screenshots op vertrouwelijke gegevens
- [ ] Zet de GitHub-repository **pas na teamcontrole** op Public
- [ ] Deel de openbare repositorylink op Canvas

**Makers:** Projectteam 721, Hogeschool Utrecht — Jesmar Oosterom en overige teamleden.
