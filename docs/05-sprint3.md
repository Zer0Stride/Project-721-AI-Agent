# Aansluiting op de Sprint 3-challenge

De challenge is vertaald naar een concrete agentopzet en een reproduceerbare voorbeeldcase.

| Onderdeel | Zichtbaar in dit project |
|---|---|
| Organisatiespecifieke agent | Inrichting in Microsoft 365 Copilot, beschreven in de README |
| Businessdoelen & Product Goal | Invoervelden, promptarchitectuur en skillontwerp |
| Userstory's, acceptatiecriteria, taken | Outputformat, uitvoerbare fictieve demo en tests |
| Kritisch beoordelen op MVP-waarde | Scorekaart met beslisregels |
| Refinementsessies | Uitgewerkt proces en notitieformulier |
| Verbeteren na feedback | Herhaalbaar prompt-/feedbackproces |
| Aantoonbare Scrumtoepassing | Refinementwerkwijze en Sprint Review-demonstratiescript |
| Canvas | Openbaar deelbare toelichting, zonder interne documenten |

**Belangrijk voor de beoordeling:** de repository laat de technische en procesmatige aanpak zien. Als een docent bevestiging vraagt van een echte refinementsessie, echte Copilot-antwoorden, een review of feedback, gebruik dan daarvoor de daadwerkelijke screenshots of notities uit de afgeschermde leeromgeving. Een openbare demonstratie wordt niet gepresenteerd als verzonnen bewijs van zulke gebeurtenissen.
