# Sprint Review — demonstratie van de AI-agent

## Korte demonstratieopbouw

**1. Introductie.** Leg uit hoe de agent Projectteam 721 helpt om van businessdoel naar een testbare story te komen.

**2. Agent tonen.** Open Microsoft 365 Copilot. Toon de agent, zijn drie voorgestelde prompts en alle zes toegevoegde skills, waaronder de refinementfeedback-skill. Houd de projectinterne inhoud afgeschermd.

**3. Generatie.** Vraag de agent met **goedgekeurde of fictieve** context om een kandidaat-userstory inclusief acceptatiecriteria en taken.

**4. Kwaliteitscontrole.** Controleer of de output businesswaarde heeft, het MVP ondersteunt, klein genoeg is en niet dubbel is.

**5. Openbare demo.** Toon de code in [demo/generate.py](../demo/generate.py), voer deze uit met fictieve context en toon de geslaagde tests.

**6. Scrum.** Leg uit dat team en opdrachtgever de kandidaatstories via refinement bespreken en pas daarna besluiten over Product Backlog en planning.

## Eén centrale vraag aan het publiek

> Is deze gegenereerde userstory waardevol en draagt hij bij aan het MVP, of moet de agent eerst aanvullende context krijgen?

De demo is begrijpelijk zonder interne documenten of toegang tot de afgeschermde agent.
